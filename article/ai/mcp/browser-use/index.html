Browser-Use ​

架构概述

一、组件 ​

核心组件 ​

  1. Agent
    • 位于browser_use/agent/service.py
    • 作为整个系统的控制中心，负责调度和执行任务
    • 通过LLM(大语言模型)做决策，生成下一步操作
    • 维护任务状态、历史记录和内存
  2. Browser
    • 位于browser_use/browser/browser.py
    • 负责管理浏览器实例（基于Playwright）
    • 提供浏览器配置和初始化功能
    • 支持多种浏览器连接方式（本地、远程、WebSocket、CDP等）
  3. BrowserContext
    • 位于browser_use/browser/context.py
    • 管理浏览器会话上下文
    • 负责获取页面状态、截图、元素选择器映射等
    • 提供与页面直接交互的底层方法
  4. Controller
    • 位于browser_use/controller/service.py
    • 负责执行具体的浏览器操作（点击、输入、滚动等）
    • 通过Registry注册和管理所有可用操作
    • 将Agent的决策转化为实际的浏览器行-
  5. DOM处理
    • 位于browser_use/dom/目录
    • 解析和处理页面DOM结构
    • 识别可点击元素、处理元素历史等
    • 为Agent提供页面结构信息
  6. Memory
    • 位于browser_use/agent/memory/
    • 提供长期记忆管理功能
    • 将详细的交互历史转换为简洁的程序性记忆
    • 优化上下文窗口使用，保持关键操作知识

辅助组件 ​

  1. MessageManager
    • 管理与LLM的消息交换
    • 处理系统提示、用户输入和模型输出
  2. Registry
    • 注册和管理可用的浏览器操作
    • 为不同页面提供特定的操作-
  3. Telemetry
    • 收集使用数据和性能指标

工作流程 ​

  1. 初始化流程
    • 创建Agent实例，配置LLM、任务和设置
    • 初始化Browser和BrowserContext
    • 设置操作注册表（Registry）和MessageManager
    • 如果启用，初始化Memory
  2. 执行循环
    • Agent.run()方法启动主执行循环
    • 每一步(step)执行以下操作:
      • 获取当前浏览器状态
      • 更新可用操作列表
      • 将状态信息发送给LLM
      • 获取LLM的决策（下一步操作）
      • 执行操作并收集结果
      • 更新历史记录和内存
  3. 执行操作
    • Controller.act()方法接收ActionModel
    • 根据操作类型调用相应的处理函数
    • 执行浏览器操作(如点击、输入、导航等)
    • 返回操作结果
  4. 内存管理
    • 定期创建程序性记忆
    • 将详细的交互历史压缩为简洁的摘要
    • 优化上下文窗口利用率
  5. 完成判断
    • 检查是否达到最大步数
    • 检查是否执行了"done"操作
    • 验证输出是否符合任务要求

二、组件详细介绍 ​

  1. Agent
    • 作为浏览器自动化代理的核心组件
    • 基于LLM进行决策，确定下一步操作
    • 管理任务状态、历史记录和记忆
    • 处理错误和异常情况
    • 支持暂停、恢复和停止功能
    • 可以生成历史记录的GIF和Playwright脚本
  2. Browser
    • 封装Playwright浏览器功能
    • 支持多种浏览器连接方式
    • 处理浏览器配置和启动参数
    • 提供新上下文创建功能
  3. BrowserContext
    • 管理浏览器会话上下文
    • 获取和处理页面状态
    • 处理元素选择和交互
    • 提供标签页管理功能
  4. Controller
    • 执行具体的浏览器操作
    • 注册和组织可用操作
    • 处理操作参数和结果
    • 提供特定域名的专用操作(如Google Sheets操作)
  5. DOM处理
    • 解析页面DOM结构
    • 识别和处理可点击元素
    • 维护元素历史记录
    • 提供元素选择和定位功
  6. Memory
    • 使用Mem0实现长期记忆管理
    • 将详细历史转换为简洁摘要
    • 优化上下文窗口使用
    • 支持多种嵌入提供商(OpenAI、Gemini等)

整体工作流程 ​

  1. 用户提供任务描述和LLM配置
  2. Agent初始化，设置Browser和Controller
  3. 执行循环开始:
    • 获取浏览器状态(URL、DOM、截图等)
    • 将状态发送给LLM进行分析
    • LLM返回决策（下一步操作）
    • Controller执行操作（点击、输入等）
    • 更新状态和历史记录
    • 如需要，更新Memory
  4. 重复执行直到:
    • 完成任务(done操作)
    • 达到最大步数
    • 遇到致命错误 Browser-use通过这种设计，实现了一个灵活、强大的浏览器自动化框架，能够利用LLM的智能进行网页交互，完成复杂的网络任务。框架的模块化设计使其具有很好的扩展性和可维护性，可以方便地添加新功能或修改现有行为。 java实现demo：https://github.com/Matthew-Miao/browser-use

二、元素高亮 ​

获取元素和设置高亮的流程 Browser-use获取页面元素和设置高亮的流程主要涉及以下几个关键步骤：

DOM树构建流程 ​

  1. 入口点：在BrowserContext.get_state()方法中，系统会调用_get_updated_state()来获取最新的浏览器状态。
  2. DOM服务初始化：_get_updated_state()方法会创建一个DomService实例，该实例负责与页面交互并获取DOM元素。
  3. 获取可点击元素：
    javascript
    dom_service = DomService(page)
content = await dom_service.get_clickable_elements(
    focus_element=focus_element,
    viewport_expansion=self.config.viewport_expansion,
    highlight_elements=self.config.highlight_elements,
)
  4. JavaScript注入：DomService.get_clickable_elements()方法会调用_build_dom_tree()方法，该方法会将buildDomTree.js脚本注入到页面中执行。

JavaScript处理（buildDomTree.js） ​

  1. 获取DOM树：buildDomTree.js是一个复杂的JavaScript脚本，它会遍历整个页面DOM树，识别并标记可交互元素。
  2. 元素识别逻辑：
    • isInteractiveElement(element) - 判断元素是否可交互（按钮、链接、输入框等）
    • isElementVisible(element) - 判断元素是否可见
    • isTopElement(element) - 判断元素是否是最顶层元素（没有被其他元素覆盖）
    • isInExpandedViewport(element, viewportExpansion) - 判断元素是否在视口内或扩展视口内
  3. 元素高亮：当doHighlightElements参数为true时，通过highlightElement(element, index, parentIframe)函数为每个可交互元素创建高亮效果：
    javascript
    function highlightElement(element, index, parentIframe = null) {

  5. 返回结果：JavaScript执行完成后，会返回一个包含DOM树结构和元素映射的对象。

  3. 返回DOM状态：get_clickable_elements()最终返回一个DOMState对象，包含DOM树和选择器映射。
  4. 清除高亮 当需要更新状态或不再需要高亮时，通过remove_highlights()方法清除高亮：
    python
    @time_execution_async('--remove_highlights')
async def remove_highlights(self):
    """
    移除所有由highlightElement函数创建的高亮覆盖层和标签。
    处理页面可能已关闭或无法访问的情况。

    try:

                const container = document.getElementById('playwright-highlight-container');

                    container.remove();

                const highlightedElements = document.querySelectorAll('[browser-user-highlight-id^="playwright-highlight-"]');

            }
            """
        )
    except Exception as e:
        logger.debug(f'⚠  Failed to remove highlights (this is usually ok): {str(e)}')
        # 不引发错误，因为这不是关键功能
        pass

视口扩展参数 ​

viewport_expansion参数控制获取元素的范围：

  • 值为0时：只获取当前视口内的元素
  • 值为正数时：获取视口扩展范围内的元素
  • 值为-1时：获取页面中的所有元素（可能导致高token使用量）
  • 元素获取和高亮的关键特性
  1. 性能优化：
    • 使用缓存机制减少DOM操作（DOM_CACHE）
    • 使用节流函数（throttleFunction）减少事件处理频率
  2. 元素选择器：
    • 使用XPath和CSS选择器两种方式定位元素
    • 支持动态属性选择器生成
  3. 元素可见性判断：
    • 检查元素是否在视口内
    • 检查元素是否被其他元素覆盖
    • 检查元素的计算样式（display、visibility、opacity等）
  4. 高亮样式：
    • 为不同类型的元素设置不同的高亮样式
    • 为每个元素添加索引标签
    • 使用半透明叠加层标记元素
  5. 动态适应：
    • 高亮会随着窗口大小变化自动调整位置
    • 支持iframe内元素的高亮 这种元素获取和高亮机制使Agent能够清晰地了解页面结构，并通过索引准确地引用和操作特定元素，是Browser-use实现精准网页自动化的核心技术之一。

三、如何操作鼠标做弹窗验证的 ​

验证码处理实现方案 这个项目使用了一种灵活的浏览器自动化方法来处理各种类型的弹窗验证，如文本验证码、图片验证码、旋转验证码等。 核心特点

  1. 多种验证码类型支持
    • 文本验证码（Text Captcha）
    • 基础图片验证码（Basic Captcha）
    • 旋转验证码（Rotate Captcha）
    • MT验证码（MT Captcha）
  2. 拖拽操作实现
    • 提供了精确的拖拽功能，这是解决旋转验证码的关键
    • 支持两种拖拽方式：基于元素选择器和基于坐标
  3. 模拟人类行为
    • 通过设置步骤数（steps）和延迟（delay_ms）模拟自然的人类鼠标移动
    • 生成中间点，使移动路径更加平滑自然
  4. 错误处理
    • 完整的错误捕获和日志记录系统
    • 在每个步骤提供详细的状态反馈

关键实现方法 ​

  1. 拖拽功能实现 拖拽功能在drag_drop方法中实现，包含三个主要步骤：
    python
    # 1. 获取元素
source_element, target_element = await get_drag_elements(
    page, params.element_source, params.element_target)

# 2. 计算坐标
source_coords, target_coords = await get_element_coordinates(
    source_element, target_element, params.element_source_offset, params.element_target_offset)

# 3. 执行拖拽
success, message = await execute_drag_operation(
    page, source_x, source_y, target_x, target_y, steps, delay_ms)
  2. 验证码处理流程 测试代码展示了不同类型验证码的处理方法：
    • 文本验证码：输入识别的文本
    • 旋转验证码：使用多次点击旋转图像到正确位置
    • MT验证码：交互式解决方案，直到验证成功
  3. 拖拽操作详细实现
    python
    # 按下鼠标
await page.mouse.down()

# 平滑移动到目标位置
for i in range(1, steps + 1):
    ratio = i / steps
    intermediate_x = int(source_x + (target_x - source_x) * ratio)
    intermediate_y = int(source_y + (target_y - source_y) * ratio)
    await page.mouse.move(intermediate_x, intermediate_y)
    
    if delay_ms > 0:
        await asyncio.sleep(delay_ms / 1000)

# 释放鼠标
await page.mouse.up()
  4. 旋转验证码特殊处理 对于旋转验证码，会使用多次点击操作，根据用户说明：
    python
    CaptchaTest(
    name='Rotate Captcha',
    url='https://2captcha.com/demo/rotatecaptcha',
    success_text='Captcha is passed successfully',
    additional_text='Use multiple clicks at once. click done when image is exact correct position.',
)

技术亮点 ​

  1. 高度模拟人类行为：通过平滑的移动路径、可调整的延迟时间和步骤数量，使自动化操作更像人类操作
  2. 灵活的元素定位：支持CSS选择器和XPath，确保能够准确找到验证码元素
  3. 完整的验证流程：包括验证前的准备、验证操作执行以及验证成功的确认
  4. 跨框架兼容性：能够处理不同类型的验证框架和验证方法 这种实现方法不依赖于传统的验证码识别API，而是通过模拟真实用户行为（点击、拖拽、旋转等）来通过验证，这使得它在不断变化的验证码场景中更加灵活可靠。 以下是使用Java实现拖拽操作来处理验证码的示例代码：

import org.slf4j.LoggerFactory;

public class CaptchaHandler {
    private static final Logger logger = LoggerFactory.getLogger(CaptchaHandler.class);
    private WebDriver driver;
    private Actions actions;
    
    public CaptchaHandler() {
        // 设置ChromeDriver选项
        ChromeOptions options = new ChromeOptions();
        options.addArguments("--start-maximized");
        
        // 初始化WebDriver
        driver = new ChromeDriver(options);
        driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(10));
        actions = new Actions(driver);
    }
    
    /**
     * 执行拖拽操作
     * @param params 拖拽参数
     * @return 操作结果
     */
    public DragDropResult dragDrop(DragDropParams params) {
        try {
            // 初始化坐标变量
            Integer sourceX = null;
            Integer sourceY = null;
            Integer targetX = null;
            Integer targetY = null;
            
            // 设置参数
            int steps = Math.max(1, params.getSteps() != null ? params.getSteps() : 10);
            int delayMs = Math.max(0, params.getDelayMs() != null ? params.getDelayMs() : 5);
            
            // 情况1：基于元素选择器
            if (params.getElementSource() != null && params.getElementTarget() != null) {
                logger.debug("使用基于元素的方式进行拖拽");
                
                // 获取源和目标元素
                WebElement sourceElement = null;
                WebElement targetElement = null;
                
                try {
                    sourceElement = driver.findElement(By.cssSelector(params.getElementSource()));
                    targetElement = driver.findElement(By.cssSelector(params.getElementTarget()));
                } catch (Exception e) {
                    logger.debug("无法通过CSS选择器找到元素，尝试XPath");
                    try {
                        sourceElement = driver.findElement(By.xpath(params.getElementSource()));
                        targetElement = driver.findElement(By.xpath(params.getElementTarget()));
                    } catch (Exception ex) {
                        logger.error("无法找到元素: {}", ex.getMessage());
                        return new DragDropResult(false, "无法找到元素: " + ex.getMessage());
                    }
                }
                
                // 获取坐标

                Point[ ] coordinates = getElementCoordinates(sourceElement, targetElement, 

                        params.getElementSourceOffset(), params.getElementTargetOffset());
                
                if (coordinates[0] == null || coordinates[1] == null) {
                    String errorMsg = coordinates[0] == null ? "无法确定源元素坐标" : "无法确定目标元素坐标";
                    return new DragDropResult(false, errorMsg);
                }
                
                sourceX = coordinates[0].getX();
                sourceY = coordinates[0].getY();
                targetX = coordinates[1].getX();
                targetY = coordinates[1].getY();
            } 
            // 情况2：直接使用坐标
            else if (params.getCoordSourceX() != null && params.getCoordSourceY() != null && 
                    params.getCoordTargetX() != null && params.getCoordTargetY() != null) {
                logger.debug("使用坐标方式进行拖拽");
                sourceX = params.getCoordSourceX();
                sourceY = params.getCoordSourceY();
                targetX = params.getCoordTargetX();
                targetY = params.getCoordTargetY();
            } else {
                return new DragDropResult(false, "必须提供元素选择器或坐标");
            }
            
            // 验证坐标
            if (sourceX == null || sourceY == null || targetX == null || targetY == null) {
                return new DragDropResult(false, "无法确定源或目标坐标");
            }
            
            // 执行拖拽操作
            boolean success = executeDragOperation(sourceX, sourceY, targetX, targetY, steps, delayMs);
            
            if (!success) {
                logger.error("拖拽操作失败");
                return new DragDropResult(false, "拖拽操作失败");
            }
            
            // 创建描述性消息
            String msg;
            if (params.getElementSource() != null && params.getElementTarget() != null) {
                msg = String.format("🖱️ 已将元素 '%s' 拖拽到 '%s'", params.getElementSource(), params.getElementTarget());
            } else {
                msg = String.format("🖱️ 已从 (%d, %d) 拖拽到 (%d, %d)", sourceX, sourceY, targetX, targetY);
            }
            
            logger.info(msg);
            return new DragDropResult(true, msg);
            
        } catch (Exception e) {
            String errorMsg = "执行拖拽失败: " + e.getMessage();
            logger.error(errorMsg);
            return new DragDropResult(false, errorMsg);
        }
    }
    
    /**
     * 获取元素坐标
     */

    private Point[ ] getElementCoordinates(WebElement sourceElement, WebElement targetElement, 

            Position sourcePosition, Position targetPosition) {

        Point[ ] result = new Point[2];

        
        try {
            // 获取源坐标
            if (sourcePosition != null) {
                result[0] = new Point(sourcePosition.getX(), sourcePosition.getY());
            } else {
                Rectangle sourceRect = sourceElement.getRect();
                result[0] = new Point(
                    sourceRect.x + sourceRect.width / 2,
                    sourceRect.y + sourceRect.height / 2
                );
            }
            
            // 获取目标坐标
            if (targetPosition != null) {
                result[1] = new Point(targetPosition.getX(), targetPosition.getY());
            } else {
                Rectangle targetRect = targetElement.getRect();
                result[1] = new Point(
                    targetRect.x + targetRect.width / 2,
                    targetRect.y + targetRect.height / 2
                );
            }
        } catch (Exception e) {
            logger.error("获取元素坐标失败: {}", e.getMessage());
        }
        
        return result;
    }
    
    /**
     * 执行拖拽操作
     */
    private boolean executeDragOperation(int sourceX, int sourceY, int targetX, int targetY, 
            int steps, int delayMs) {
        try {
            // 移动到源位置
            actions.moveByOffset(sourceX, sourceY).perform();
            logger.debug("已移动到源位置 ({}, {})", sourceX, sourceY);
            
            // 按下鼠标
            actions.clickAndHold().perform();
            
            // 使用中间点平滑移动到目标位置
            for (int i = 1; i <= steps; i++) {
                double ratio = (double) i / steps;
                int intermediateX = (int) (sourceX + (targetX - sourceX) * ratio);
                int intermediateY = (int) (sourceY + (targetY - sourceY) * ratio);
                
                actions.moveByOffset(intermediateX - sourceX, intermediateY - sourceY).perform();
                sourceX = intermediateX;
                sourceY = intermediateY;
                
                if (delayMs > 0) {
                    Thread.sleep(delayMs);
                }
            }
            
            // 移动到最终目标位置
            actions.moveByOffset(targetX - sourceX, targetY - sourceY).perform();
            
            // 再次移动确保dragover事件正确触发
            actions.moveByOffset(0, 0).perform();
            
            // 释放鼠标按钮
            actions.release().perform();
            
            return true;
        } catch (Exception e) {
            logger.error("拖拽操作过程中发生错误: {}", e.getMessage());
            return false;
        }
    }
    
    /**
     * 旋转验证码处理
     */
    public boolean handleRotateCaptcha(String imageSelector, double rotationDegree) {
        try {
            WebElement rotateImage = driver.findElement(By.cssSelector(imageSelector));
            Rectangle rect = rotateImage.getRect();
            
            // 中心点
            int centerX = rect.x + rect.width / 2;
            int centerY = rect.y + rect.height / 2;
            
            // 计算旋转所需的拖拽距离
            double radius = Math.min(rect.width, rect.height) * 0.4;
            double startAngle = 0;
            double endAngle = Math.toRadians(rotationDegree);
            
            // 起始点
            int startX = centerX + (int)(radius * Math.cos(startAngle));
            int startY = centerY - (int)(radius * Math.sin(startAngle));
            
            // 终点
            int endX = centerX + (int)(radius * Math.cos(endAngle));
            int endY = centerY - (int)(radius * Math.sin(endAngle));
            
            // 执行拖拽
            DragDropParams params = new DragDropParams();
            params.setCoordSourceX(startX);
            params.setCoordSourceY(startY);
            params.setCoordTargetX(endX);
            params.setCoordTargetY(endY);
            params.setSteps(20); // 更多步骤使旋转更平滑
            params.setDelayMs(10); // 稍微延迟使旋转更自然
            
            DragDropResult result = dragDrop(params);
            return result.isSuccess();
            
        } catch (Exception e) {
            logger.error("处理旋转验证码失败: {}", e.getMessage());
            return false;
        }
    }
    
    /**
     * 解决点击验证码
     */

    public boolean handleClickCaptcha(String[ ] selectors) {

        try {
            for (String selector : selectors) {
                try {
                    WebElement element = new WebDriverWait(driver, Duration.ofSeconds(5))
                            .until(d -> d.findElement(By.cssSelector(selector)));
                    element.click();
                    // 每次点击后稍微等待，让UI更新
                    Thread.sleep(500);
                } catch (Exception e) {
                    logger.warn("点击元素 {} 失败: {}", selector, e.getMessage());
                }
            }
            
            // 点击提交按钮
            WebElement submitButton = driver.findElement(By.cssSelector("button[type='submit']"));
            submitButton.click();
            
            // 等待验证结果
            return new WebDriverWait(driver, Duration.ofSeconds(10))
                    .until(d -> d.getPageSource().contains("Verified Successfully"));
            
        } catch (Exception e) {
            logger.error("处理点击验证码失败: {}", e.getMessage());
            return false;
        }
    }
    
    /**
     * 解决滑块验证码
     */
    public boolean handleSliderCaptcha(String sliderSelector, String targetSelector) {
        try {
            WebElement slider = driver.findElement(By.cssSelector(sliderSelector));
            WebElement target = driver.findElement(By.cssSelector(targetSelector));
            
            // 获取滑块和目标位置
            Point sliderPos = slider.getLocation();
            Point targetPos = target.getLocation();
            
            // 计算需要滑动的距离
            int xOffset = targetPos.getX() - sliderPos.getX();
            
            // 构建拖拽参数
            DragDropParams params = new DragDropParams();
            params.setElementSource(sliderSelector);
            params.setCoordSourceX(sliderPos.getX());
            params.setCoordSourceY(sliderPos.getY());
            params.setCoordTargetX(sliderPos.getX() + xOffset);
            params.setCoordTargetY(sliderPos.getY());
            params.setSteps(30);  // 滑块需要更平滑的移动
            params.setDelayMs(15); // 更自然的延迟
            
            DragDropResult result = dragDrop(params);
            return result.isSuccess();
            
        } catch (Exception e) {
            logger.error("处理滑块验证码失败: {}", e.getMessage());
            return false;
        }
    }
    
    public void close() {
        if (driver != null) {
            driver.quit();
        }
    }

    这个Java实现包含了以下核心特性：
    1. 多种验证码处理： ○ 旋转验证码：通过计算旋转角度进行精确拖拽 ○ 点击验证码：依次点击指定元素 ○ 滑块验证码：准确计算滑动距离
    2. 拖拽模拟： ○ 支持基于元素选择器和坐标两种方式 ○ 使用中间点生成平滑的拖拽轨迹 ○ 配置步骤数和延迟使操作更加自然
    3. 错误处理： ○ 完整的异常捕获和日志记录 ○ 详细的操作结果反馈
    4. 灵活配置： ○ 通过DragDropParams类提供灵活的参数配置 ○ 支持自定义操作步骤和延迟 这种实现方法在处理各类验证码时可以很好地模拟人类行为，减少被识别为机器人的可能性。

#!/usr/bin/env python
# -*- coding: utf-8 -*-

from langchain_deepseek import ChatDeepSeek
from browser_use import Agent
import asyncio
from dotenv import load_dotenv

# 加载环境变量
load_dotenv()

async def main():
    # 创建Agent实例
    agent = Agent(
        task="1、打开https://chat.deepseek.com   2、如果未登录，等待登录  3、输入问题：找出java是世界上最好的语言的核心论点 4、点击发送按钮等待数据返回",
        llm=ChatDeepSeek(
            model="deepseek-chat",  # 使用 deepseek-chat 模型
            max_tokens=4000,  # 限制输出token数
            temperature=0.7,  # 增加一些随机性
        ),
        enable_memory=False,  # 暂时禁用内存功能，避免使用 sentence-transformers
        max_actions_per_step=10,  # 限制每步最大动作数
    )
    
    try:
        # 运行自动化任务
        await agent.run()
    except Exception as e:
        print(f"发生错误: {e}")
    finally:
        # 确保正确关闭浏览器
        await agent.close()

if __name__ == "__main__":
    # 运行异步主函数
    asyncio.run(main())
